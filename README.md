# Tak Jdem? pro podniky

Veřejná prezentace a návod k obsluze aplikace pro restaurace, kavárny a další podniky.

Otevřete `index.html` a vyberte prezentaci nebo návod. Návod zahrnuje registraci, aktivaci podniku, nastavení, rezervace, zrušení a tahák pro směnu. Prezentace má 12 slidů, animované přechody, mobilní ovládání a tisk do PDF. Návod má obsah, vyhledávání a tisk.

Všechny obrázky a písma potřebná k zobrazení jsou součástí tohoto repozitáře. Kontakt a formulář odkazují na takjdem.com. Projekt připravuje pilot v Praze. Návod odpovídá kódu aplikace k 3. říjnu 2026.

Tento repozitář obsahuje pouze prezentační materiály. Všechna práva k obsahu a značce vyhrazena.
